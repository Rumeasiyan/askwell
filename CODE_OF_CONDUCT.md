# Code of Conduct

## The short version

Be decent. Assume good faith. Criticise ideas, not people.

## Standards

**Expected:** courtesy toward others, openness to disagreement, graceful acceptance of correction, and focus on what is best for the project and its users.

**Unacceptable:** harassment of any kind, personal or political attacks, insulting or derogatory comments, publishing others' private information without permission, sexualised language or imagery, and any conduct that would reasonably be considered inappropriate in a professional setting.

## Technical disagreement is not misconduct

This project runs on stated reasoning and recorded decisions. Saying *"this is wrong and here is why"* — about the architecture, the plan, a constraint, or a maintainer's judgement — is welcome and is how the specification improved. Doing it rudely is not.

## Scope

Applies in all project spaces — issues, pull requests, discussions, commit messages — and when representing the project publicly.

## Reporting

Report through **GitHub's private reporting** on this repository, or by opening a private security advisory if the matter is sensitive. Reports go to the maintainer and are not public.

**Be aware of the practical reality:** this is a single-maintainer project. There is no committee, no HR function and no appeals process. Reports are handled by one person, as fairly as one person can. Serious conduct issues will result in removal from the project's spaces.
