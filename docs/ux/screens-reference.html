The margin is not optional

Three screens from the core loop. The specification is in docs/ux/ — these images are a reference, and where they disagree with the written spec, the spec wins.

Every AI product right now is a centred chat column with sources hidden behind a toggle. VaultQ's whole claim is that answers are checkable, so the evidence sits in a permanent right-hand margin, joined to the claim it supports. An uncited sentence is visibly wrong: nothing sits beside it.

Ask — answered

Serif is language, mono is machinery. Hover a claim to raise its source. The green is spent on nothing except things you can trace; the ochre marks what VaultQ guessed rather than was told.

What the colours mean

The palette encodes how VaultQ knows a thing. That is a hard rule: spend the green anywhere else and it stops meaning anything.

provenance
You can check this. Citations, source cards, leaders, the query behind a number. Never a button.
inferred
I guessed. Unconfirmed memory, inferred types, an injected LIMIT. Correct me.
ink
My own words. Answers, and abstention — which is not a failure and is never red.
alarm
Something broke. Failed ingestion, unreachable database. Nothing else, ever.
