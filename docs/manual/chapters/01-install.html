Install Askwell

Askwell runs on your own computer. Nothing you add to it is uploaded. You need:

  • Windows 11, version 22H2 or newer, or Linux (Fedora, Ubuntu, or a distribution built on Ubuntu), or macOS on Apple silicon.
  • Free disk space for Askwell itself, the AI models it downloads on first start (about 5 GB on most computers), and the index of your files.
  • Askwell measures your computer's memory and graphics card when it starts, and picks a model that fits. More memory means faster answers.
  • An internet connection for the installation and the model download. After that, Askwell works offline.

Check what you downloaded

Askwell is not code-signed, so Windows and macOS warn you before they run it. The warning means your computer cannot confirm who published the file. A checksum is how you confirm it is the file that was published. Check it before running anything.

  1. From the release page, download the file for your computer and the file SHA256SUMS.
  2. Work out the checksum of your download.
    • Windows, in PowerShell: Get-FileHash Askwell-Setup-<version>.exe -Algorithm SHA256
    • Linux and macOS, in a terminal: shasum -a 256 askwell-<version>-<platform>.tar.gz
  3. Compare it with the line for your file in SHA256SUMS.

If the two values do not match, stop. Do not run the file. Report it on the project's issue page: a mismatch means the file changed after it was published.

Windows

  1. Double-click Askwell-Setup-<version>.exe.
  2. Windows shows Windows protected your PC. Click More info, the small link above the buttons, then Run anyway.
  3. Windows asks for administrator permission. Click Yes. Setup needs it to install the services Askwell runs on.
  4. Click through the welcome and licence pages, then Install. Setup installs whatever this PC is missing: Podman, the Windows Subsystem for Linux, Docker Compose, Python and Microsoft's Visual C++ runtime. Each step is shown as it happens. This takes several minutes.
  5. If Setup says Windows needs to restart once, leave Restart now selected and click Finish. After the restart, sign in. Setup carries on by itself and tells you when it is done.
  6. When Setup says Askwell is installed and opening, Askwell opens. It is also in your Start menu.

Setup changes one Windows setting, and says so in its log: it sets the Windows Subsystem for Linux to mirrored networking, which is how Askwell's services reach its AI on your PC.

If Setup stops with a message about virtualisation, your PC's firmware has virtualisation turned off. Setup names the setting. It is in the BIOS or UEFI setup, not in Windows, so you change it there, then run Setup again.

If Setup cannot finish, it saves a text file on your Desktop whose name starts with Askwell-Setup-report. Nothing is sent anywhere. See When something goes wrong.

Linux

  1. Open a terminal in the folder you downloaded to, and unpack the download: 
    tar -xzf askwell-<version>-linux-x86_64.tar.gz
  2. Run the installer: 
    askwell-<version>-linux-x86_64/deploy/linux/install.sh
  3. It lists what your computer is missing (Podman, Docker Compose and the OpenMP runtime) and asks before installing them. Answer y. It asks for your password once.
  4. It then sets up Askwell and opens it. Askwell is also in your applications menu.

On a distribution other than Fedora or Ubuntu, the installer stops before changing anything and tells you what to install yourself.

macOS

  1. Open Terminal in the folder you downloaded to, unpack the download and run its installer: 
    tar -xzf askwell-<version>-macos-arm64.tar.gz
askwell-<version>-macos-arm64/deploy/macos/install.sh
    It installs Podman and Docker Compose with Homebrew if they are missing, and places Askwell in Applications.
  2. macOS refuses the first launch: Askwell cannot be opened because the developer cannot be verified. Click Done.
  3. Open System Settings → Privacy & Security and scroll to Security. Next to the line saying Askwell was blocked, click Open Anyway, then confirm.

You do this once. Afterwards Askwell opens normally.
